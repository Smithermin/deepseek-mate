隐私权政策

最后更新：2026 年 5 月 23 日

DeepSeek Mate（以下简称"本扩展"）尊重并保护您的隐私。本隐私权政策说明本扩展如何收集、使用和保护您的信息。

1. 信息收集

本扩展在您使用过程中会处理以下信息（全部保存在您本机，除非下文明确说明）：

  • 对话内容：当您使用收藏功能时，本扩展会保存您当前对话中的问题与回答内容，存放在浏览器本地（chrome.storage.local / IndexedDB）。
  • 历史对话记录：当您启用「历史对话搜索」时，本扩展会通过 DeepSeek 官方接口获取您在 chat.deepseek.com 上的历史对话记录，仅存放在本机，用于本地搜索。
  • 提示词数据：您自定义的提示词内容，存放在本机。
  • 长期记忆：启用「记忆」功能后，本扩展会让模型从您的对话里提炼关于您的长期信息（例如身份、偏好、正在做的项目、技术栈；也可能包含您主动提到的身体/健康与生活处境类信息），存放在本机，用于在后续对话中作为上下文。
  • 设置与凭证：扩展设置；若您自行配置了第三方 LLM API，其中的 API Key 会以明文保存在本机 chrome.storage.local（仅本机，不会上传给我们）。

2. 信息使用

本扩展处理的信息仅用于以下目的（均在本机完成，下列需要联网的步骤会明确说明）：

  • 在侧边栏中展示您收藏的对话、历史记录与长期记忆
  • 提供本地搜索功能，帮助您快速查找历史对话
  • 导出对话为 Markdown / 压缩包
  • 创建分享链接（通过 DeepSeek 官方接口）
  • 记忆提取：见第 5 节 —— 这一步会把对话文本发送给模型（DeepSeek 官方接口，或您自行配置的第三方 API）
  • 会话分叉 / 会话压缩：把您选定会话的上下文（压缩时还包括模型生成的摘要）作为新会话的第一条消息发送到 DeepSeek 官方接口

3. 信息共享

本扩展不会向任何第三方出售、出租或共享您的个人信息，不包含任何分析、广告或追踪代码，也没有自建服务器。

唯一会把数据发到本机之外的情形是：

  • DeepSeek 官方接口（chat.deepseek.com / api.deepseek.com）：读取您授权访问的历史对话、创建分享链接、发送会话分叉/压缩内容、以及记忆提取时把对话文本交给模型。这些请求都带着您自己的登录凭证或您自己填的 API Key，直接发给 DeepSeek，不经过我们。
  • 您自行配置的第三方 LLM API（可选，默认关闭）：如果您在设置里填写了 Base URL 与 API Key 并启用，记忆提取等后台任务会改为请求您指定的那个域名，发送的内容是该次提取所需的对话文本与现有记忆条目。扩展会在启用时单独申请该域名的访问权限。

4. 数据存储与删除

所有数据均存储在您的浏览器本地（chrome.storage.local 与扩展源的 IndexedDB）。您可以随时：

  • 在侧边栏中删除单条收藏、历史记录或记忆，或使用「清空所有记忆 / 清空所有」
  • 在 Chrome 扩展管理页面清除扩展数据，或卸载扩展（会一并清除）

扩展自身创建的临时会话：记忆提取会在您的 DeepSeek 账号里创建带「【临时】」标记的工作会话，为了避免"建完就删"的脚本特征，它们会先保留、再由扩展分批自动清理（默认保留约 45 分钟后、每 3 分钟最多清理 2 个）。您也可以在列表里自行删除。

您自己会话的处理：会话分叉不会修改原会话；会话压缩会给原会话标题加「压缩前」前缀，并按您的设置决定它是否进入「临时会话」分组（进入该分组意味着约 45 分钟后会被自动删除）或「归档」分组（保留）。默认设置为「不挪动」。

5. 数据传输

除第 3 节列出的两类目标（DeepSeek 官方接口、您自行配置的第三方 API）之外，本扩展不会把您的数据发送到任何其他服务器；也没有自建后端用于收集数据。所有通信均通过 HTTPS 加密。

记忆提取（默认关闭，需显式开启或手动点击）会把当次需要的对话文本（与现有记忆条目）交给模型处理。如果您对某段对话的敏感性有顾虑，请不要对它执行提取，或改用本机可控的自建 API。

读取删除请求：当「历史对话搜索」开启时，扩展会读取 chat.deepseek.com 页面发出的「删除会话」请求（仅取其中的会话 ID，不读取正文），用于把本地镜像里对应的会话记录一并移除。关闭该开关后，扩展不会读取页面上的任何请求。

6. 权限说明

本扩展申请了以下 Chrome 权限及其用途：

  • storage：在本机保存收藏、设置、长期记忆等
  • unlimitedStorage：历史对话全文索引可能超过默认配额
  • sidePanel：在浏览器侧边栏展示收藏/搜索/记忆等界面
  • tabs：找到 chat.deepseek.com 标签页以触发同步、与页面内脚本通信
  • notifications：收藏成功等操作的本机提醒
  • downloads：导出 Markdown / 压缩包
  • host_permissions: https://chat.deepseek.com/*：注入收藏按钮、读取历史对话、发送分叉/压缩内容
  • optional_host_permissions（可选，仅在您启用时申请）：https://api.deepseek.com/* 用于官方 API 通道；https://*/* / http://*/* 用于您自行填写的第三方 API 域名

7. 儿童隐私

本扩展不面向 13 岁以下儿童，不会故意收集儿童的个人信息。

8. 隐私权政策的变更

本隐私权政策可能会不时更新。如有重大变更，我们会在扩展的更新说明中通知您。
