更新记录

最新的在最上面。装扩展后会自动更新，也可以在 edge://extensions 里手动检查。

1.1.1

最新
  • 修复：从中间某一轮回答分叉时，分支点之后的附件会被一起带进新会话（现在只带分支点之前的）
  • 分叉 / 压缩 / 记忆提取加入了操作间隔，避免被 DeepSeek 官方风控
  • 会话压缩的摘要可以走你配置的自定义 API（未配置时仍走网页通道），失败会自动回落

1.1.0

已发布
  • 新增 长期记忆：从对话里提炼关于你的长期信息，新对话自动带上； 对话内可折叠面板显示"这次带了哪几条"，记忆库可搜索 / 编辑 / 置顶 / 删除
  • 新增 会话分叉与会话压缩：把上下文带进新会话；压缩先生成交接摘要； 原会话标题加「【压缩前】」，去向可选保留 / 临时 / 归档
  • 新增：⋯ 菜单里的扩展入口收成一个分组，更新后有一次轻提示
  • 改进：修复收藏按钮"有时不显示"；收藏上限 200 → 1000，本地历史索引 200 → 2000

1.0.x

历史版本
  • 收藏问答、导出 Markdown
  • 历史对话同步到本地 + 全文搜索
  • 提示词管理与 @ 引用
  • 回车键换行开关
